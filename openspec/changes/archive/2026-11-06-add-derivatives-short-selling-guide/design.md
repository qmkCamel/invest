## Context

现有基础文档偏重财报估值，技术文档偏重价格结构，衍生品机制缺少连续讲解。本次教学范围具有完整阅读顺序，混入术语表会使入口过重。

## Goals / Non-Goals

- 目标：一份详细、可复算、可独立阅读的期权／期货／卖空指南；一个券商资料日期快照。
- 非目标：交易执行、行情服务、保证盈利的策略、真实账户资产归档。

## Decisions

1. `options_futures_short_selling_guide.md` 作为机制教材，按概念、期权、敏感度、做市与期权墙、卖空、期货、保证金、决策流程组织，并使用目录锚点与表格。
2. `broker_derivatives_reference_2026-11-06.md` 保存富途香港公开收费、保证金机制、长桥香港支持情况的证据等级。未读取到的动态保证金保留缺口，不以其他券商报价代替。
3. README 和三份已有学习文档仅增加导航，保留当前未提交的市场结构增补；归档时通过新增 requirement 合并主规格。
4. 来源优先 OIC/OCC、SEC、CME、Nasdaq 和券商官方帮助。公式案例自行构造；报价、Greeks、风险预算均非实时报价或交易建议。
5. 不引入软件依赖。Markdown 可离线阅读，外部链接用于来源复核。检查相对路径、锚点、表格结构和关键公式，不运行与文档无关的人口网页测试。

## Risks / Trade-offs

- 长文可能难读：提供分阶段阅读顺序、术语表、案例及自测。
- 费率会过期：日期记录与机制分开，读者执行前以账户订单预览核实。
- 到期 payoff 被误当成任何时候的损失边界：单列实物交割、提前指派、拆腿和新股票头寸风险。
- OI 推断可能被过度解读：明确多空配对、做市商净仓未知，期权墙是模型条件而非确定价位。

## Validation

复算权利金、价差到期表、Delta/Gamma、Black-Scholes 对冲、NQ/MNQ 点值、追保和费用预算；校验所有新增入口及相对链接；运行 change 严格校验、归档后主规格严格校验和 git diff --check。仅文档变更，浏览器交互检查不适用。
