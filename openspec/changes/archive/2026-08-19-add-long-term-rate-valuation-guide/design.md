## Context

“利率上涨压低高估值”同时包含两个概念：未来现金的现值下降，以及安全资产收益提高后股票必须提供更高的预期回报。若只给结论，零基础读者容易把所有利率变化机械地理解成买卖信号。

## Goals / Non-Goals

**Goals:**

- 用生活化数字说明未来现金为何会因折现率上升而贬值。
- 解释安全资产收益上升如何改变持有股票的机会成本。
- 帮助读者判断哪些公司更依赖遥远未来、因而通常更敏感。
- 明确利率只是估值变量之一，不是单独的交易信号。

**Non-Goals:**

- 不教授债券久期、WACC 或 CAPM 的完整计算。
- 不判断当前利率方向，不提供真实公司的目标价或买卖建议。
- 不把 2% 和 5% 的演示参数描述为当前市场数据。

## Decisions

1. **承接 DCF 章节。** 将新知识点放在 DCF 之后，让读者先理解折现，再看利率如何改变折现率。
2. **拆成两条传导路径。** 分别说明“未来现金现值下降”和“安全资产吸引力上升”，避免把两个原因混在一句话中。
3. **使用相同终值和不同现金流期限。** 用十年后的 100 元展示纯折现效应，再用成熟公司和成长公司解释现金流远近造成的敏感度差异。
4. **加入反例和决策边界。** 明确盈利上调可能抵消估值压缩，利率上涨不意味着所有股票必跌，也不能据此追涨杀跌。

## Risks / Trade-offs

- [把无风险利率理解为绝对无风险] -> 在术语表说明仍有通胀、期限、价格和汇率等风险。
- [把利率与股价理解为机械反向关系] -> 加入盈利增长、估值起点、负债和现金流期限等共同变量。
- [把教学数字误认为实时市场数据] -> 全部标注为虚构假设，并避免使用当前收益率表述。
