## Context

独立术语文档使用“白话解释、真实案例、常见误判”的教学方式。DCF 涉及多个相互依赖的概念，如果只列公式，读者容易会计算却不理解每个数字代表什么。

## Goals / Non-Goals

**Goals:**

- 用一家虚构小店串起未来现金、折现、终值、负债和每股价值。
- 让读者能够复述每一步在回答什么问题。
- 用估值区间和敏感性提醒代替虚假的精确答案。

**Non-Goals:**

- 不教授完整 WACC、CAPM 或三表建模。
- 不提供真实公司的目标价和实时估值。
- 不把演示参数描述为通用建议。

## Decisions

1. **先讲故事，再给公式。** 读者先理解“买下小店能拿到多少现金”，再看到现值公式，降低术语门槛。
2. **使用企业自由现金流路线。** 以“经营现金流减资本开支”作为入门近似，最后减净负债得到股权价值；同时标明专业建模还需处理营运资金、税和融资口径。
3. **使用整数化演示。** 数字仅服务步骤理解，不追求小数精度；最终强调估值区间而非单点结果。
4. **保留适用边界。** 对银行、亏损成长企业和强周期企业明确提示该简化模型可能失真。

## Risks / Trade-offs

- [案例过度简化] → 明确它是教学模型，并列出专业模型还需细化的项目。
- [读者机械套用折现率和永续增长率] → 标注所有参数是虚构演示，要求做悲观、基准、乐观三种情景。
- [终值占比过高却被忽略] → 单独解释终值并要求检查其占总价值比例。
