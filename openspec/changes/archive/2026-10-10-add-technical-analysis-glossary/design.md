## Context

仓库使用独立 Markdown 教材与相对链接组织知识。技术分析内容目前散落在策略文档中，基础术语表主要聚焦财报和估值。

## Goals / Non-Goals

- 提供可离线阅读正文、适合新手查询的中文教材，覆盖已有策略使用的技术术语。
- 用表格、公式、连续案例和自测解释用途与限制。
- 不修改历史估值快照、不提供实盘信号、不增加图表应用或自动交易。

## Decisions

1. 独立创建 `technical_analysis_glossary.md`，避免把估值文档扩充成难以查阅的综合教材。
2. 每类术语配白话解释和误区；重点展开 SMA/EMA、MACD、RSI、KDJ、BOLL 与 ATR。
3. 明确周期、复权、未收盘数据、指标命名及平滑口径差异；所有价格与参数案例标为虚构教学。
4. 使用核对过的官方券商教育资料并按章节引用，区分公式定义与经验解读。
5. 验证 Markdown 相对链接、表格与围栏结构、案例算术及 OpenSpec；本次没有 HTML/JS 变更，无需仪表盘浏览器测试。

## Risks / Trade-offs

- 读者可能把金叉、超卖或形态当作必然信号：逐项注明失效条件，并提供假突破案例。
- 不同软件数值可能不同：说明参数、复权、初始化与 MACD 柱线倍数，避免混用。
- 盈亏比可能被误认为盈利保证：区分目标盈亏比与历史平均盈亏比，说明费用、胜率和滑点影响。
